# 战斗吧

回合制即时战略。每回合先用 15 秒给单位下令，再观看最多 30 秒的自走。一期是本地单机：你对一名规则 AI，在 16×16 格子地图上摧毁对方主基地即获胜。

## 玩法

1. 大厅点「开始本地对局」。
2. **操作阶段**（15 秒，战场静止）：给己方单位或建筑下达一条指令，或打出手牌。可以提前结束。
3. **自走阶段**：单位按指令移动、采集、建造、维修、生产和战斗。走完后进入下一轮。未完成的指令会保留。

**操作**

- 左键选中己方单位或建筑，再点空地取消。
- 右键平地移动，右键敌人攻击，右键资源点采集。
- 建造、巡逻、维修、生产、停止在右侧面板。
- 底部手牌：紧急修缮、火力覆盖、战地鼓舞。点卡再点目标。

工人每回合最多走 6 格，战斗单位 8 格。选中对象可在右侧资料卡查看属性和简介。

更完整的规则见 [`docs/requirements.md`](docs/requirements.md)。

## 快速运行

需要 **Node.js 22+** 和 **pnpm 9**。

```bash
corepack enable
corepack prepare pnpm@9.15.9 --activate
pnpm install
pnpm dev
```

浏览器打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)，选难度后开始对局。

```bash
pnpm test        # 模拟与 AI 单测
pnpm typecheck   # TypeScript 检查
```
